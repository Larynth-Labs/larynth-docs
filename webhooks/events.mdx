Every event arrives in the same envelope. Only `data` changes. Fields marked optional are left out when they have no value.

```json
{
  "id": "msg_0123456789abcdef",
  "type": "call.ended",
  "timestamp": "2026-11-01T12:00:00Z",
  "data": {}
}
```

When you create an endpoint, `event_types` lists the types it receives. It needs at least one type. `GET /v1/webhooks/event-types` returns the current list.

Amounts ending in `_micro` are micro-USD, millionths of a dollar. Times are UTC in RFC 3339; `started_at` and `answered_at` on call events carry fractional seconds. The examples use made-up data.

There are 67 event types. 9 of them are never sent today and are marked **Not sent** below. You can subscribe to them, but nothing arrives.

## Calls

### call.started

A call is created and begins ringing or connecting.

```json
{
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "direction": "inbound",
  "from": "+14155550123",
  "to": "+14155550100",
  "assistant_id": "3f1c6e0a-5b1d-4c3e-9a57-2d0f4c8d1e11",
  "started_at": "2026-11-01T11:57:00.412083Z"
}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. Use it with `GET /v1/calls/{call_id}`. |
| `direction` | `inbound`, `outbound` or `web_test`. |
| `from`, `to` | E.164 numbers. |
| `assistant_id` | Optional. |
| `campaign_id` | Optional. Present for campaign calls. |
| `started_at` | When the call began. |

### call.answered

A call is answered, by the agent on an inbound call or by the person you dialed on an outbound call.

```json
{
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "direction": "outbound",
  "from": "+14155550100",
  "to": "+14155550123",
  "assistant_id": "3f1c6e0a-5b1d-4c3e-9a57-2d0f4c8d1e11",
  "campaign_id": "a2b9d1c4-2e6f-4f0b-8f1d-7c3e5a9b0d12",
  "answered_at": "2026-11-01T11:57:02.118764Z"
}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. |
| `direction` | `inbound`, `outbound` or `web_test`. |
| `from`, `to` | E.164 numbers. |
| `assistant_id` | Optional. |
| `campaign_id` | Optional. Present for campaign calls. |
| `answered_at` | When the call was answered. |

Calls that are never answered send `call.started` and `call.ended`, but no `call.answered`.

### call.ended

A call finishes, for any reason. Sent once per call.

```json
{
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "direction": "outbound",
  "status": "completed",
  "cause": "normal",
  "answered_at": "2026-11-01T11:57:02.118764Z",
  "ended_at": "2026-11-01T11:59:41Z",
  "billable_ms": 159000,
  "bridged_ms": 0,
  "from": "+14155550100",
  "to": "+14155550123",
  "assistant_id": "3f1c6e0a-5b1d-4c3e-9a57-2d0f4c8d1e11",
  "campaign_id": "a2b9d1c4-2e6f-4f0b-8f1d-7c3e5a9b0d12"
}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. Use it with `GET /v1/calls/{call_id}`. |
| `direction` | `inbound`, `outbound` or `web_test`. |
| `status` | Final status, for example `completed`, `no_answer`, `busy`, `failed`, `canceled` or `rejected`. |
| `cause` | Why the call ended. |
| `answered_at` | Optional. Missing when the call was never answered. |
| `ended_at` | When the call ended. |
| `billable_ms` | Billable time in milliseconds. Billing rounds up per started minute and some calls are free. See [billing](/concepts/billing). |
| `bridged_ms` | Time the call spent connected to a person after a transfer, in milliseconds. |
| `from`, `to` | E.164 numbers. |
| `assistant_id` | Optional. |
| `campaign_id` | Optional. Present for campaign calls. |
| `flow` | Optional. For flow agents: `outcome`, `path` and, when set, `variables`. |
| `bookings` | Optional. Bookings made on the call, each with `id`, `status` and `start_at`. |

### call.analyzed

The post-call summary and extracted data are ready. Sent after `call.ended`, only when post-call analysis ran.

```json
{
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "assistant_id": "3f1c6e0a-5b1d-4c3e-9a57-2d0f4c8d1e11",
  "summary": "The caller asked to move Tuesday's appointment to Thursday afternoon. Confirmed for 3 pm.",
  "data": {
    "new_time": "Thursday 3 pm"
  },
  "successful": true,
  "reason": "The appointment was rescheduled."
}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. |
| `assistant_id` | Optional. |
| `summary` | Plain-language summary of the call. |
| `data` | The fields you defined for extraction, with the values found. |
| `successful` | Optional. Whether the call met the success goal, when you set one. |
| `reason` | Optional. Why `successful` has its value. Present with `successful`. |

You can also read this with `GET /v1/calls/{call_id}/analysis`.

### call.recording.ready

A call recording is stored and verified. Fetch the audio with `GET /v1/recordings/{id}/audio`. Each download is audited.

```json
{
  "recording_id": "b6d0f3a2-91c4-4e7e-8d05-5a2c7f1e9b34",
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "source": "call",
  "format": "wav/pcm16/16000/mono+age",
  "bytes": 5088000,
  "frames": 2544000
}
```

| Field | Description |
| --- | --- |
| `recording_id` | The recording. |
| `call_id` | The call. |
| `source` | Which audio the recording holds. |
| `format` | Audio format. |
| `bytes` | Stored size in bytes. |
| `frames` | Number of audio frames. |

### call.transferred

An agent hands a call to a person.

```json
{
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "direction": "inbound",
  "destination": "+14155550188",
  "mode": "warm",
  "method": "sip_refer",
  "outcome": "completed",
  "target": "Front desk",
  "at": "2026-11-01T11:58:20Z",
  "sip_code": 200
}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. |
| `direction` | `inbound`, `outbound` or `web_test`. |
| `destination` | E.164 number the call went to. |
| `mode` | How the hand-off worked, for example `warm`. |
| `method` | The transfer method. |
| `outcome` | How the hand-off ended. |
| `target` | The name you gave the destination. |
| `at` | When it happened. |
| `sip_code` | Optional. Final signalling code. |

The values of `mode`, `method` and `outcome` can grow over time, so don't treat them as closed lists.

### call.flagged

A live call needs attention: the caller asked for a person, or the line has been silent for a long time.

```json
{
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "flag": "human_requested",
  "at": "2026-11-01T11:58:02Z",
  "assistant_id": "3f1c6e0a-5b1d-4c3e-9a57-2d0f4c8d1e11"
}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. |
| `flag` | `human_requested` or `long_silence`. |
| `at` | When the flag was raised. |
| `assistant_id` | Optional. |

### call.alert.fired

A call alert rule (`GET /v1/alert-rules`) with the `webhook` channel matched a call.

```json
{
  "rule_id": "5e0b3c97-4a18-4d6f-b2e5-1c9a7d8f0b36",
  "rule_name": "Callback wanted",
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "trigger": "call_analyzed",
  "matched": {
    "field": "callback_requested",
    "value": true
  }
}
```

| Field | Description |
| --- | --- |
| `rule_id` | The alert rule. |
| `rule_name` | The rule's name. |
| `call_id` | The call that matched. |
| `trigger` | `call_analyzed` or `live_turn`. |
| `matched` | What matched: the `field` and its `value`. Long text is cut to 200 characters. |

```json
  "mode": "listen",

}
```

| Field | Description |
| --- | --- |
| `call_id` | The call. |
| `supervision_id` | This supervision session. |
| `user_id` | The team member. |
| `mode` | `listen` or `takeover`. |
| `channel` | `browser` or `phone`. |
| `at` | When they joined. |

## Compliance

### compliance.opt_out

A person asked not to be called again. Sent when a revocation is recorded, whether from a call, a campaign or the API. The number is added to your internal do-not-call list.

```json
{
  "revocation_id": "5c1f8e29-3b7a-4d60-a2e4-8f9b0c6d1a35",
  "e164": "+14155550123",
  "channel": "in_call",
  "call_id": "call_01J9ZK3Q8M2V7X4N6P5R1T0WYB",
  "revoked_at": "2026-11-01T11:58:02Z",
  "category": "",
  "scope": "all"
}
```

| Field | Description |
| --- | --- |
| `revocation_id` | The revocation. |
| `e164` | The number. |
| `channel` | Where the opt-out came from, for example `in_call`. |
| `call_id` | The call, when there was one. |
| `revoked_at` | When it was recorded. |
| `category` | The kind of calls the person opted out of. Empty means all. |
| `scope` | `all`, `telemarketing` or `informational:<category>`. |

## Billing

### billing.balance.low

Your balance needs attention. The payload differs for each case.

```json
{
  "tenant_id": "c8a1e5d3-7f02-4b96-8e41-2d6a9f0b3c57",
  "reason": "inbound_call_refused"
}
```

| Field | Description |
| --- | --- |
| `available_micro`, `threshold_micro` | When the balance fell below your low-balance threshold. |
| `reason` | `inbound_call_refused` when a call was refused because the balance is empty, `credits_exhausted` when a campaign paused for lack of credit (with `campaign_id`), or `number_rental` when a number's rent could not be paid (with `number_id`, `amount_micro` and `release_on`). |

Amounts are in micro-USD, millionths of a dollar.

### billing.top_up.succeeded

A top-up added credit.

```json
{
  "payment_id": "e9d2b7a4-1c85-4f03-b6a8-0d3e7c5f1b92",
  "amount_micro": 20000000,
  "kind": "top_up"
}
```

| Field | Description |
| --- | --- |
| `payment_id` | The payment. |
| `amount_micro` | Credit added, in micro-USD. |
| `kind` | `top_up` for a top-up made through checkout. |

### billing.auto_top_up.failed

An auto top-up failed.

Larynth does not send this event. Auto top-up is off and your card is never charged without you. Top up through checkout when your balance is low.

### billing.spend_limit.alert

Spend reached a threshold of your daily cap or monthly budget.

```json
{
  "period": "monthly",
  "threshold_pct": 80,
  "cap_micro": 500000000,
  "used_micro": 401250000,
  "stop_inbound": false
}
```

| Field | Description |
| --- | --- |
| `period` | `daily` or `monthly`. |
