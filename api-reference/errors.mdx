---
title: Errors
description: Errors are RFC 9457 problem+json responses with a stable code you can match on.
---

Failed requests return a non-2xx status and a body with the content type `application/problem+json`.

```json
{
  "type": "https://larynth.com/problems/billing.insufficient_credit",
  "title": "Insufficient credit",
  "status": 402,
  "code": "billing.insufficient_credit",
  "detail": "Add credit to place this call."
}
```

| Field | Description |
| --- | --- |
| `code` | Stable machine-readable code. Match on this, not on `title` or `detail`. |
| `type` | A stable URI for the code: `https://larynth.com/problems/<code>`. |
| `title` | Short summary of the code. |
| `status` | The HTTP status. |
| `detail` | Explanation of this occurrence. May change over time. |
| `errors` | On validation errors, a list of field-level problems. |
| `retry_at` | When the request may next succeed, for example when a calling window opens. |

Compliance denials use the code of the rule that blocked the call, which starts with `dial.`. Two examples are `dial.denied` and `dial.caller_id.not_allowed`.

## Handling errors

- `4xx` means the request needs to change. Do not retry it unchanged, except `429`.
- `429` means slow down. Wait for the number of seconds in the `Retry-After` header, then retry.
- `5xx` means a problem on our side. Retry with backoff. For requests that place calls, send an [Idempotency-Key](/api-reference/idempotency) so a retry cannot place a second call.

## Error codes

### Requests

| Status | Code | Title |
| --- | --- | --- |
| `400` | `request.invalid` | Bad request |
| `404` | `resource.not_found` | Not found |
| `405` | `request.method_not_allowed` | Method not allowed |
| `406` | `request.not_acceptable` | Not acceptable |
| `409` | `resource.conflict` | Conflict |
| `413` | `request.body_too_large` | Request body too large |
| `415` | `request.unsupported_media_type` | Unsupported media type |
| `422` | `request.validation_failed` | Validation failed |
| `429` | `rate_limited` | Rate limit exceeded |
