<Update label="November 21, 2026" description="Developers" tags={["Developers"]}>
  ## API reference

  `GET /v1/calls/{call_id}/recording/audio` streams both sides of a call as one mono WAV, with byte ranges.
  `GET /v1/calls/{call_id}/recording/peaks` returns waveform peaks for the caller and the agent on one timeline.
  The `recording` object on a call gains `lanes` and `started_offset_ms`, which is when recording started relative to `answered_at`.
  `GET /v1/catalog/ambient-sounds` lists the background sounds. `call_handling.ambient_sound` takes a key from that list, and the new `call_handling.ambient_level` sets the volume: `low`, `medium` or `high`.
  [Calls](/concepts/calls) now describes the optional `reason` on `POST /v1/calls/{call_id}/end` and the values of `hangup_by`.
  Webhook event type groups now include `bookings`, `issues`, `tools`, `knowledge` and `integrations`.
</Update>

<Update label="November 20, 2026" description="Developers" tags={["Developers"]}>
  ## API reference

  New endpoints record, remove and play an assistant's greeting in your own voice: `PUT` and `DELETE /v1/assistants/{id}/draft/greeting-audio`, and `GET /v1/assistants/{id}/versions/{v}/greeting-audio`.
  `GET /v1/catalog/presets` lists builder presets with price and latency, and `GET /v1/catalog/price-estimate` returns the price per minute and expected latency of a model selection.
  Catalog models report `retires_on`, `latency_p95_ms`, `latency_samples`, `latency_source` and `latency_measured_at`, and `latency_basis` is now `live` or `lab`.
  [Errors](/api-reference/errors) now describes the request rate limit and the `Retry-After` header on `429`.
</Update>

<Update label="November 18, 2026" description="Developers" tags={["Developers"]}>
  ## API reference and webhooks

  The API reference now lists every public endpoint, including alerts, analytics, issues, practice calls and call texts.
  The webhook pages describe all event types with a sample payload for each.
  `call.started` and `call.answered` are sent.
  `GET /v1/inbox` accepts an `assignee` filter, and the spam allow list is paginated.
</Update>

<Update label="November 15, 2026" description="Product" tags={["Product"]}>
  ## Call alerts

  Choose which calls send you an alert, and where it goes.
  Start from a preset, or write your own rule.
  Text alerts are available where they are turned on for your workspace.
</Update>

<Update label="November 15, 2026" description="Product" tags={["Product"]}>
  ## Listen in and take over

  Listen to a live call, take it over, or hand it back to the agent.
  This is available when it is turned on for your workspace.
</Update>

<Update label="November 15, 2026" description="Product" tags={["Product"]}>
  ## Suggested answers

  When callers keep asking a question your agent could not answer, Larynth lists it.
  Add an answer from the list to close the gap.
</Update>

<Update label="November 14, 2026" description="Product" tags={["Product"]}>
  ## Analytics

  A new Analytics page shows usage, call outcomes, agents and reply speed.
</Update>

<Update label="November 14, 2026" description="Product" tags={["Product"]}>
  ## Delete a caller's data

  Delete everything about one caller by phone number from Settings, Data.
  Billing records, opt-outs and consent records are kept.
</Update>
